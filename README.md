# RiZhi

RiZhi 是一个面向日程安排、课程表、每日记录和阶段提醒的桌面端原型。它会根据任务标签和时间段，在任务开始、结束、课程课间、工作/学习休息节点弹出桌面提醒。

## 当前页面

- 任务：按日期查看和编辑当日安排，底部 `+` 可新增单条任务；“批量创建任务”可手动创建课表/每日安排、导入文件或复用前一天安排。
- 个人：设置课程提醒时间，以及工作/学习提醒时间。
- 记录：按日期填写每日生活记录，也会尝试从表格文件中的记录内容或批注导入。
- 设置：查看当前月份数据文件和设置文件路径，可选择数据文件夹；支持二次确认后删除某一天数据或重置全部软件数据。

任务和记录会按月保存在本地 JSON 文件中。默认路径位于程序根目录下的 `memory` 文件夹：

```text
WHBR PC/memory/whbr-data-YYYY-MM.json
WHBR PC/memory/whbr-settings.json
WHBR PC/memory/whbr-settings-location.json
```

其中：

- `whbr-data-YYYY-MM.json`：保存对应月份的任务安排和每日记录。
- `whbr-settings.json`：保存自定义数据文件路径等设置。
- `whbr-settings-location.json`：当你把设置文件改到别的位置时，用来记录新的设置文件地址，保证下次启动仍能找到它。

软件“设置”页会显示这些完整路径。数据文件夹和设置文件都可以改成你指定的位置，方便按月归档、备份或迁移。

设置页主界面只显示数据文件和设置文件。`whbr-settings-location.json` 是内部定位文件：只有当设置文件被移动到自定义位置时，软件才需要通过它找到新的设置文件地址，因此只在重置确认中列出。

删除功能包括：

- 删除某一天数据：删除该日期的全部任务安排和每日生活记录。
- 重置全部数据：删除 RiZhi 写入的数据文件、设置文件、内部定位文件，并清理旧版浏览器存储。

删除前会弹出二次确认，并列出将影响的内容。重置全部数据会涉及：

- 数据文件：保存任务安排和每日记录。
- 设置文件：保存自定义数据文件路径。
- 内部定位文件：保存自定义设置文件路径。
- 旧版浏览器存储键：`whbr.tasks`、`whbr.journals`。

## 文件解析

- 图片：目前保留本地 OCR/视觉接口代码作为后续扩展入口。
- 表格：进入 `src/parsers/scheduleParser.js`，本地解析年份、日期、时间段、任务、记录内容和批注。

Excel 月计划工作流：

- 一个工作簿代表一个月。
- 每个 sheet 代表一天，例如 `8.30`、`9.1`。
- 软件会尝试把 sheet 名转换成日期，并附加到当天的任务条目上。
- 软件会尝试读取表格行中的记录正文，以及任意单元格批注；批注会按上下文尽量归入每日记录、任务详情或任务反思。
- 导入整个月后，任务页按“查看日期”筛选显示，不会把整个月同一作息全部堆在同一天界面里；重复导入同一条安排会自动去重。
- 表格提取会忽略没有明确时间段的行，也会过滤纯序号、勾叉、情况标记等非任务内容。
- 手动新增和导入文件得到的任务使用同一种布局。时间、任务条目、事前计划可在列表中直接编辑；右侧详情入口用于填写实际完成与反思，并评价完成情况：未评价、已完成、部分完成、未完成。
- 每个条目右侧有删除按钮和拖拽手柄，可拖动调整当天条目顺序。

表格推荐列名：

```text
日期, 星期, 时间段, 课程/任务, 地点, 类型
2026-08-28, 周五, 14:20 - 18:10, 软件工程课, A301, 课程
```

也支持 `开始时间`、`结束时间` 分列。

## 运行

```powershell
cd "WHBR PC"
npm install
npm start
```

注意：需要通过 Electron 启动软件，点击 `+` 才能调用系统文件选择器。直接双击打开 `src/index.html` 只能看到静态界面，不能完整访问本地文件系统。

基础检查：

```powershell
npm run check
```
