# 日织

日织是一款面向 Windows 的本地日程与生活记录软件，用于安排每天的工作、学习、课程和生活任务，记录实际完成情况，并通过周期统计观察时间投入与生活节奏。

任务、生活记录、标签和附件默认保存在本机。除检查 GitHub Releases 更新、首次下载离线语音模型以及同一局域网内的手机附件上传外，日常使用不需要将个人记录发送到外部服务。

## 安装与更新

1. 在 GitHub 仓库右侧进入 **Releases**。
2. 打开标记为 **Latest** 的版本，下载安装程序并按提示完成安装。
3. GitHub Releases 发布新版本后，旧版本启动时会询问是否更新。选择更新会下载并安装新版本，原有 `memory` 数据不会被清理。

正常卸载软件时，卸载程序会询问是否同时删除个人数据；软件自动更新时不会弹出该询问。

## 任务

- 按日期查看当天安排，可使用日期框旁的上下按钮切换前一天和后一天。
- 底部 `+` 用于新增任务。任务支持时间段、名称、标签、任务目标、实际完成内容与反思、完成情况。
- 时间段发生重叠时，冲突任务的时间会标红；前一项结束时间与后一项开始时间相同不算冲突。
- 支持拖动调整任务顺序，并可通过编辑菜单或快捷键撤销、重做任务修改。
- 可以把当前日期的完整安排保存为模板，之后在“批量创建任务”中复用。模板只保存时间段、任务名称和任务标签。

### 批量创建任务

“批量创建任务”提供两类入口：

- **课表**：手动填写学期课表，或导入 `xlsx`、`xls`、`csv`、`tsv` 课表文件。导入后会先预填课表，课程时间段仍可由用户校对和补充。PDF 课表暂不支持导入。
- **每日安排**：复用安排模板，或为单日、连续多日填写安排。每日安排支持本地语音创建任务，不支持从表格或 PDF 文件导入。

语音创建任务时，建议按“开始时间到结束时间、任务标题、具体任务内容”的顺序描述。识别文字和解析结果都可以在确认前修改。

## 记录

- 按日期填写每日生活记录，并使用自定义色块标签标记不同类型的日子。
- 支持本地语音输入。识别出的文本会插入编辑框，用户确认内容后仍需手动保存。
- “上传照片”会创建一个局域网上传页面。电脑与手机连接同一 Wi-Fi 或局域网时，可扫码上传照片、动态图片和视频，确认后归档到当前记录日期。
- “记录列表”支持显示全部、按日期筛选、按标签筛选和文字搜索。
- 点击记录条可查看当天的生活记录、任务目标、具体完成内容与反思、完成情况，以及已归档的照片和视频。

## 个人

“个人”页提供自律统计，可按本日、本周、本月、本季度和本年查看：

- 安排数量与完成评价；
- 总安排时长；
- 工作、课程、学习、生活等任务类型的平均每日投入时间与占比。

## 设置

- **数据文件**：查看统一存放位置，以及月度数据、设置、照片和视频、语音模型的实际路径；更改存放位置时，相关内容会一并迁移。
- **数据删除**：按单日或日期范围选择性删除任务、生活记录和附件，也可以重置全部本地内容。所有删除操作都会二次确认。
- **标签**：新增、删除和编辑记录标签的颜色、简称与完整说明。
- **周期设置**：设置每节课程与课间时长，以及工作/学习的专注与休息周期。
- **语音识别测试**：下载或检查离线模型，选择麦克风，并测试输入波形和本地识别结果。

窗口关闭时可以选择退出软件，或最小化到系统托盘继续接收任务提醒。左下角定位按钮可返回任务页并定位到当前正在进行的安排。

## 离线语音识别

日织使用本地离线语音模型完成记录和任务的语音识别：

- 首次使用需要联网下载约 840 MB 的模型文件；
- 下载完成后，录音识别在本机进行；
- 设置页可查看模型状态、测试麦克风和识别效果；
- 更改统一存放位置时，已安装模型会随其他日织数据一起迁移。

## 本地存储

任务和记录按月保存为 JSON 文件。默认存放位置位于当前 Windows 用户的数据目录：

```text
C:\Users\用户\AppData\Roaming\rizhi\memory\rizhi-data-YYYY-MM.json
C:\Users\用户\AppData\Roaming\rizhi\memory\rizhi-settings.json
C:\Users\用户\AppData\Roaming\rizhi\memory\images\
```

- `rizhi-data-YYYY-MM.json`：保存对应月份的任务安排和每日记录。
- `rizhi-settings.json`：保存标签、提醒周期、安排模板和自定义路径等设置。
- `images`：按月份和日期保存记录中归档的照片与视频。

实际路径以软件“设置 → 数据文件”中显示的内容为准。可以选择新的统一存放文件夹，用于迁移、备份或归档。

## 开发

```bash
npm install
npm start
```

检查主进程、渲染进程、解析器、存储模块及现有测试：

```bash
npm run check
```

打包命令：

```bash
npm run pack
npm run dist
```
