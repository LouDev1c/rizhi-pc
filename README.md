# 日织

日织 是一个面向每日任务规划与记录的自律软件。用户在每天开始时设置当天待办，结束时记录发生过的事，在任务进行期间劳逸结合保持状态。软件设计时力求实现简洁的UI界面和功能，使用时不采集任何用户隐私信息。

## 页面

- 任务：按日期查看和编辑当日安排，底部 `+` 可新增单条任务；“批量创建任务”可手动创建课表/每日安排、导入文件或复用前一天安排。
- 个人：设置课程提醒时间，以及工作/学习提醒时间。
- 记录：按日期填写每日生活记录，也可以从表格文件中的记录内容或批注导入。
- 设置：查看当前月份数据文件和设置文件路径，可选择数据文件夹；支持二次确认后删除某一天数据或重置全部软件数据。


## 存储

任务和记录会按月保存在本地 JSON 文件中。默认路径位于系统用户数据目录下的 `memory` 文件夹：

```text
C:\Users\用户\AppData\Roaming\RiZhi\memory\rizhi-data-YYYY-MM.json
C:\Users\用户\AppData\Roaming\RiZhi\memory\rizhi-settings.json
```

其中：

- `rizhi-data-YYYY-MM.json`：保存对应月份的任务安排和每日记录。
- `rizhi-settings.json`：保存自定义数据文件路径等设置。

软件“设置”页会显示这些完整路径。数据文件夹和设置文件都可以改成你指定的位置，方便按月归档、备份或迁移。
